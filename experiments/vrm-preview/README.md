# 独立 3D 预览试验台

本地 VRM 验证项目，和 Live2D 扩展分开运行，不调用 AI、不安装形象、不改 Coo 配置。

## 启动

双击 `start.cmd` 会启动本地服务并自动打开浏览器；服务已经运行时直接复用，不再启动第二份。
也可在此目录运行 `npm start`，手动打开终端输出的地址。默认端口是 `4783`，仅监听 `127.0.0.1`。
页面地址应为 `http://127.0.0.1:4783/`。直接从资源管理器打开 `index.html` 时会自动转到这个地址；
这仍要求服务先启动。自定义端口时通过 `start.cmd` 或终端输出的地址进入。
本机优先复用旧 3D 工作台已经安装的 Three.js 0.180.0、three-vrm 3.4.2 和 esbuild 0.25.10；
没有这些依赖时，在本目录执行 `npm install`。也可用 `VRM_ENGINE_ROOT` 指向已安装同版本依赖的项目。
构建产物和进程记录位于忽略的 `.local/`，源码独立位于本目录。

可以点击「打开 VRM」或拖入单个 `.vrm`，文件直接在浏览器内读取，不上传、不复制素材。
默认只读引用旧工作台的原始 `aldina.vrm`。可用环境变量 `VRM_SAMPLE` 换成本机另一个样本；
不存在样本时仍可自行打开 VRM。样本是用户已有的本地练习素材，不包含在项目或构建产物中。

## 可以查看什么

- VRM 0.x / 1.0 的人形骨骼加载、MToon 贴图和模型自带的弹簧物理；当前实测样本是 VRM 0.x。
- 旋转、缩放、平移、全身和面部取景，浅色／深色／网格背景，截图。
- 待机、招手、点头、摇头、鞠躬、原地走路六种通用骨骼试动作。动作平滑进出；停止归位。
- 模型实际声明的全部表情，保留原名称，单选试用、强度调整，以及眨眼、视线和说话口型试播。
- 姿态动作和面部表情可叠加；自动眨眼和口型遵守模型的表情覆盖规则；不推断自定义表情语义。
- 实际几何、骨骼、贴图尺寸、渲染读数，以及暂停、恢复、复位与重复换模型。

通用动作是本试验台的程序化演示，不是对模型自带动画的识别。没有接入 VRMA、VMD、PMX、
音频舞蹈、重定向、脚底 IK、桌面运动或 Coo Body/kit。原地走路仅用于观察骨骼驱动，不保证足底锁定。
模型原始骨骼比例、贴图、表情和物理参数不被写回、裁剪或重编码。控制台可能显示源 VRM 的旧版规范兼容提示。

导入只接受自包含的 VRM / GLB 容器；拒绝外部贴图或缓冲链接，避免意外联网。单文件上限为 128 MiB。
文件损坏或不支持时保留已经载入的模型；新模型解析成功后才释放旧模型。WebGL 上下文丢失时提示刷新。

## 验证

`npm test` 核对 GLB 格式、外部资源限制与动作包络；浏览器实测记录保存在忽略的 `artifacts/`。
独立预览通过不等于通过 Coo 形象沙箱或扩展契约；此项目不是 World 扩展，不执行扩展安装检查。

## 许可

自有代码沿用主项目许可。Three.js 和 three-vrm 采用 MIT，构建时把对应许可保存到
`.local/THIRD_PARTY_LICENSES.txt` 并在页面提供入口。模型素材受各自许可约束，不随本项目分发。

官方加载流程依据：[three-vrm 3.4.2](https://github.com/pixiv/three-vrm/tree/v3.4.2/packages/three-vrm)。

## 本机验证记录（2026-11-02）

用未压缩的 aldina.vrm 在本机 Chrome 的真实 WebGL 环境验证：28,492 个源三角面、53 个人形骨骼、
17 个表情、最大贴图边 2048。招手叠加开心、六种试动作、循环与结束归位、暂停后调整表情、
口型、全身／面部取景、透明截图、损坏文件回退与说明弹窗通过。三个连续重新加载后的 GPU
纹理和几何数量保持一致；源模型 SHA-256 未变化。1440／900／720／540／390 宽度无横向溢出。
测试过程没有页面错误或对外请求。记录及截图位于忽略的 `artifacts/`。

这只证明上述样本和独立浏览器路径；VRM 1.0、其他体型、长时间资源稳定性及 Coo 沙箱尚未实测。

入口排障：用户截图中的纯文字页面来自 `file:///…/index.html`。旧入口使用站点根路径，
本地文件直开时样式和脚本缺失。现以相对经典脚本处理文件入口跳转，HTTP 入口保持同源 CSP；
启动器等待服务就绪后再打开，端口被其他程序占用时拒绝误用。该修复不修改 Coo 或模型素材。
