# 自主互动实现记录

## 2026-11-03：平地行走与交流状态升级

仍为独立试验台，版本 0.1.0；不改 Coo、AstrBot、Live2D 主项目或用户模型。

- `src/locomotion.js`：在只含骨骼的探针上采样官方适配后的动画，测量足部高度、支撑时段和后移速度。世界位移只由控制器推进一次；局部动画保留身体摆动。起步、慢走、短停步、转身使用 Overte/Hanami 原字节素材。
- 以慢走和短停步替换第一轮快走/长停步组合。首轮实模发现长停步配固定减速会把支撑目标留得过远；改为按当前片段支撑足后移速度推进位移，阶段切换重新建立约束。
- `src/performance.js`：行走接管全身基础动画，手部叠加保留；用当前姿态桥接，支撑脚世界目标锁定，必要时降低骨盆保证腿长可达。落点保留，结束后转回观察者并恢复原来的待机。
- `src/engagement.mjs`：注意、倾听、思考、说话、空闲状态，情绪平滑保持与衰减。与 `BehaviorDirector` 共用一次注视积分，避免指针与交流状态重复争用。
- `src/speech.js`：分析实际输出的 Web Audio 波形，音频时钟推进口型和进度；结束、取消、暂停与页面生命周期统一处理。冷启动时等音频时钟实际推进后再进入说话状态。
- `sample-speech.mjs`：使用 Windows 已安装的离线语音生成原创试听句，音频及元数据只放 `.local/`。当前隔离环境不能选用语音，已通过本机离线生成；不接外部服务。
- `src/app.js`：完整互动序列带取消代号，模型切换、手动状态和打断会取消后续步骤；用户手动上身动作允许与行走叠加。舞台取景扩大到本次平地移动范围，原布局与原生表情保留。

新增测试使用真实随附 VRMA 和 VRM 0/1 两种合成人形骨架，检查阶段、位移、落点、支撑、暂停、重定向和取消；同时检查情绪延续与打断闭嘴。真实整模仍只用本机 aldina（VRM 0.x），不据此推断所有模型质量。

本轮最终验证：12 项 Node 测试通过，构建通过。隔离 Chrome / 真实 WebGL 连续记录 382 个状态样本，完整互动、真实音频强弱和静音间隙、身体与音频同时暂停、打断闭嘴、取消行走序列、上身手势叠加、三次模型重载和五种窗口宽度通过。当前样本受约束脚部最大位置误差为 0.000940 米；三次重载均为 17 个 GPU 纹理与 14 个几何。源 VRM 摘要未变化，无页面错误或对外请求。

## 数据与职责

- `src/clips.mjs`：原创备用待机、两种点击回应及手动手势关键帧。角度使用度，骨盆位移按身高归一化。
- `src/behavior.mjs`：持续时钟、注意力停留／转移、眼睛到头部到上身的阻尼响应、不等间隔眨眼、回应冷却。
- `src/performance.js`：官方 VRMAnimation 适配、Three.js AnimationMixer 交叉过渡、局部叠加、表情优先级及双腿约束。
- `src/app.js`：只读导入、渲染、输入命中和 UI。点击必须命中模型，任一时刻拖动超过阈值就不能再当点击处理。

待机、手势、注意力和表情分别保留状态。手动动作优先于自动回应；手动原生表情优先于自动面部变化。
暂停停止身体和行为时间，仍允许查看不同视角及手动改表情。减少动态效果时默认暂停，用户可主动恢复。
关掉自主互动保留基础待机和显式试播，眨眼与视线由各自开关控制。

## 帧求值顺序

1. 恢复上一帧保存的“纯动画输出”，推进行为和片段混合。
2. 保存本帧纯动画输出，再施加分层注视。幅度只改变叠加手势权重，保留成品待机姿态。
3. 手动切换动作时以当前姿态为起点过渡，避免重复播放或打断产生突跳。
4. 更新双脚约束；走路试播逐渐释放约束，收尾再恢复。
5. 求值视线与原生表情，遵守模型自带的眨眼、视线、嘴部覆盖规则。
6. 由 three-vrm 更新原骨架及原始弹簧物理，然后绘制。

Three.js PropertyMixer 会跳过数值未变化的轨道。直接在其输出上持续追加注视会使固定骨骼逐帧积累旋转，
实画检查发现头颈逐渐转过头。已改为先恢复纯动画姿态再叠加，连续运行检查确认无累积。
未修改模型弹簧参数、网格、贴图或源文件。
