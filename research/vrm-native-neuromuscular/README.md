# VRM 特化神经肌肉系统研究资料库

本项目要为 VRM 设计完整的人工神经肌肉身体，使角色能够围绕意图实时组织动作。资料搜集覆盖标准、功能解剖、生物力学、神经运动控制、人工身体设计、肌肉控制、降阶、接触、部署与数据资源。

核对日期为 **2026 年 11 月 3 日，Asia/Shanghai**。资料库收录 **72 条来源记录**，包含论文、规范、官方文档、模型与代码仓库；论文及其配套代码合并记录。条目中 **38 条标为核心相关 P0**。阅读深度逐条列出，不把取得摘要、查看项目介绍与读过方法和实验段混为一谈。

## 项目研究约定

用户已经明确项目出发点：现成方案没有提供要创造的完整系统，因此以原创设计为立项前提。现有研究用于理解机制、提取可用知识和构造实验。完整系统的目标包括 VRM 特化的驱动结构、内部动态状态、感觉反馈、局部反射和全身协调。

当前只进行资料搜集与研究。资料独立保存在本目录。既有扩展、VRM 预览与本机 Coo 的实现不属于本轮改动范围。

## 对设计直接有用的资料结论

**VRM 可以定义统一身体接口，但没有给出完整的物理身体。** 标准提供骨骼语义、层级、姿态兼容和表现通道。关节活动范围、质量、惯性、驱动力和主动身体接触需要我们明确设计或估计。[Humanoid 规范](https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/humanoid.md)

**人工肌肉不需要与人体肌肉一一对应。** 2013 年的工作已采用近似肌肉模板并优化路径和参数，为虚构生物建立完整的肌肉驱动运动。它提供了可以阅读和借鉴的结构设计方法。[作者项目页](https://www.cs.ubc.ca/~van/papers/2013-TOG-MuscleBasedBipeds/index.html)

**控制降维与身体简化需要分开研究。** SAR 压缩控制表示并保留任务专属路径；DynSyn 从动力学结构构造状态相关协同。二者为协调机制提供依据，但低维策略本身不意味着物理执行器和全部状态已被删除。[SAR](https://sites.google.com/view/sar-rl)、[DynSyn](https://arxiv.org/abs/2407.11472)

**内部状态能够通过后续运动表现出来。** MuJoCo 把执行器激活明确作为位姿、速度之外的动态状态。因此设计不能只用一帧骨骼姿态判断某种机制是否有用。[执行器动态状态](https://mujoco.readthedocs.io/en/stable/computation/index.html#stateful-actuators)

**浏览器存在真实物理与策略闭环的实现入口。** 官方 MuJoCo WASM 和 mjswan 提供可研究的部署路径；后者列出了肌肉角色示例。实际帧率仍由指定模型、硬件、步长、线程和策略共同决定。[官方 WASM](https://github.com/google-deepmind/mujoco/blob/main/wasm/README.md)、[mjswan](https://github.com/ttktjmt/mjswan)
