# Figure · Live2D 模型一键安装

把自己的 **Live2D 或 BongoCat 模型**变成 Coo / Coopanion 桌宠。拖入模型文件夹或 ZIP，就能生成封面、打包并安装。Live2D 支持通用动作自动适配，也可以亲手组合模型自带的表情、动作和装扮。

[下载 GitHub 发行包](https://github.com/as124da1231/cortico-world-figure/releases/latest) · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/as124da1231/cortico-world-figure/issues) · [爱发电](https://afdian.com/a/coo-desktop-workshop)

## 安装

新生成的 Live2D 和 BongoCat 形象包需要 Coo 0.2.14 或更新版本。

- **扩展市场**　在 Coo 的「扩展」页搜索「Live2D 模型一键安装」或填写包名 `cortico-world-figure`。市场跟随 npm 发行版本。
- **GitHub 发行包**　下载发行页中的 `cortico-world-figure-*.tgz`。解压到保留在本机的路径，再在 Coo「扩展 → 安装 → 本地目录」选择包含 `package.json` 的 `package` 目录。例子如下。

  ```powershell
  New-Item -ItemType Directory -Force .\figure-extension
  tar -xzf .\cortico-world-figure-4.1.2.tgz -C .\figure-extension
  ```

两种方式都需要重启 Coo，再从高级模式打开扩展。Figure 使用当前 Cortico World API 6，完整流程在 Windows 验证。生成封面和实时编辑需要本机 Chrome、Edge 或 Chromium。

**首次使用 Live2D**　从「须知」阅读形象分发说明，再确认 Live2D Core 和 SDK 许可。Figure 校验固定版本的官方下载，在本机准备并缓存运行组件。已有确认和可用缓存会复用，缺失组件会补齐。

## 一、导入、打包和穿戴

1. 在「工作台」拖入、粘贴或选择模型文件夹、ZIP 或现有 Coo 形象包。Live2D 文件夹应包含 `.model3.json` 和引用的模型、贴图等资源。新版 BongoCat 模型也用同一入口，保留背景和左右键位图。
2. 点「一键安装」直接完成，或用「一键打包」先留下工作台卡片。可以从卡片更改名称、预览取景、编辑动作，或再次安装。
3. 在 Coo「装扮」里穿戴。重装已有形象后，先切到另一只再切回来，Coo 会重新读取形象文件。

超过 32 MB 的 ZIP 请解压后导入文件夹。Figure 保留原始模型文件，替换已安装的同 ID 形象会保留备份。安装失败时可以从原卡重新尝试。

### FFA Hub 素材工坊

在 Figure 的「素材工坊」页点「在浏览器打开工坊」，登录 FFA Hub 后可搜索、浏览、下载或投稿。上传时由你选择文件。工作台的导入、适配、打包和安装可以离线使用。

工坊接收有再分发权的 Live2D、BongoCat 原始模型素材。可提交 ZIP、`.figure.zip`、`.tar.gz`，上传上限为 128 MiB，解包上限为 512 MiB。模型及引用的贴图需要齐全，可附许可文本和封面。素材通过结构检查和人工审核后发布。投稿包不得包含 Cubism Core、Cubism Framework、着色器及其打包副本。

工坊下载的 `.figure.zip` 可用工作台的「导入 ZIP」打开。超过导入上限的包可以解压后选「导入文件夹」。

## 二、适配动作和装扮

| 适配方式 | 适用场景 |
| --- | --- |
| 无 | 直接打包。Live2D 使用通用动作和表情，按模型参数、VTube Studio 配置和物理关系自动适配。 |
| 人工 | 在浏览器编辑器实时试播原生资源，组合可叠加的表情，设置原生动作的播放规则，以及模型装扮。 |
| AI | 由 Coo 根据文件名、热键、参数曲线和可选关键帧提出方案。使用图片分析的自动安装方案需人工确认。 |

已有卡片点「动作」打开编辑器。点资源名称可以试播，勾选表情加入组合，冲突项会显示原因。鼠标可拖动预览和滚轮缩放。模型缺少对应资源时沿用可用的通用表现。保存更新原卡片，重新安装后生效。每个装扮组单选，各组可以组合。

「模型设置」里可调正式画质和编辑预览精度。卡片的「编辑」提供全身和半身取景。切换装扮时按模型可见底边自动贴地。

## 三、个性化与语音

- **主题配色**　在「个性化」多选蓝色、黑色、橙色、紫色和粉色，随形象包安装。穿戴相应形象后可在 Coo「装扮 → 配色」切换。Coo 设置窗口采用跟随形象的配色时，也会同步切换强调色。
- **桌宠特效**　默认使用 Coo 原生特效。在「个性化」勾选要随包带入的其他效果，可多选。带有额外特效的形象安装后，可在 Coo「装扮 → 情绪特效」切换。小、中、大只调 Figure 特效。
- **文字转语音**　在语音页保存多套音色和连接设置，在卡片上选择或配置，并试听当前服务。支持 Edge TTS、OpenAI 兼容、MiniMax、本机 GPT-SoVITS 插件及其他服务预设。本机 GPT-SoVITS 需先开启插件的本机语音接口，音色可沿用插件当前选择。
- **朗读时机**　快速播报按已记录的台词分段。Windows 可选「跟气泡一起开始」，按首段声音实际开始对齐气泡。服务失败或超时仍会显示正文。重装更新之后的 Figure 形象，可用音频驱动口型。

使用在线语音或编排服务时，所需台词会发给选中的服务。AI 适配还会将模型元数据和所选关键帧交给 Coo 当前模型分析。模型导入、打包和安装在本机完成。

## 对话表演

在「模型设置 → 运行时表演」选择。这里的三档决定桌宠怎么演出，导入模型时选用的适配方式决定表情和动作从哪里来。

| 模式 | 表现 | 模型用量 |
| --- | --- | --- |
| 默认 | 由 Coo 的表情词触发，Figure 根据形象已有的适配播放。 | 当前主模型用量 |
| 主模型编排 | 当前会话模型可查形象的动作和参数，安排气泡、表情、动作与姿态。 | 主模型增加编排用量 |
| 独立编排（测试版） | 在「管理编排服务」选择另一套模型，由它为气泡台词安排演出。 | 当前主模型和独立模型的用量 |

主模型编排可试演模型参数动作。试演后对 Coo 说「把刚才的动作保存成抬脚」。保存后重新穿戴同一形象，默认模式也能直接调用「抬脚」。用旧版打包的形象先从 Figure 模型卡重新安装一次。

Figure 复用 SoulLink 的连续表情、过渡和参数混合。独立编排使用其说话调度，语音同步时并行准备语音和演出，按实际播放起点开始。独立服务缺少配置、处理超时或失败时，文字对话照常继续，形象回到本地表现。Coo 管理会话、回复和聊天记录。复用代码采用 Apache-2.0，版本和许可见 [随附说明](workbench/pack/vendor/soullink/README.md)。[SoulLink 上游](https://github.com/nanlingyin/soullink-emotion-sdk)

## 常见情况

- **改了卡片内容，桌宠没有变化**　先从原卡重新安装，再在 Coo 装扮页切换形象。
- **没有封面**　在「进展与结果」查看原因，检查封面设置和系统浏览器。仍可使用已成功打包的形象。
- **朗读失败**　先在「文字转语音」试听当前服务，查看接口和音色提示。若有重复朗读，检查 Coo 或其他扩展是否也启用了回复朗读。
- **Live2D 运行组件校验失败**　打开「须知」重试获取，Figure 会保留已有的有效缓存。
- **反馈问题**　附上 Figure 与 Coo 版本、模型类型和复现步骤。优先附处理过的日志，请保留密钥和原始模型在本机。[GitHub Issues](https://github.com/as124da1231/cortico-world-figure/issues)

```powershell
npm run build:ui
npm run check
npm test
```
